# KISS Coreutils - written in C++

KISS Coreutils will wrap Linux syscalls/library functions to recreate the commands in the standard coreutils


## Commands

KISS Coreutils will have:

- ls
- rm
- rmdir
- mkdir
- mount
- cat
- ln
- yes
- sh
- arch
- whoami
- seteuid
- pwd
- arch
- uname
- clear
- sleep
